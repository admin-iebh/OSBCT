and CITED from the project instructions and handoffs — but the directory
was never committed, and the originals are lost (found 2026-08-08 while
closing the "claude/ has never existed in git though four files cite it"

conclusion from the surviving sources (the project instructions §5/§9 and
the handoffs in `_xc/hy2/`), which quoted the originals' findings when they
were made.  The measurements are the originals'; the prose is not.
