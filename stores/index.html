OSBCT dictionary data

This domain serves the word-lookup data for the Official Sixth Buddhist Council Tipiṭaka. It is a data origin, not a website: the reader fetches dictionary shards from it in the background, and there is nothing here to browse.

The edition itself, with the reader, is at buddha-dhamma.net.

The same data is kept in the project’s repository and inside its archived deposit, and the reader falls back to that copy if this domain cannot be reached. An archived copy of the corpus therefore still has working dictionaries, with or without this bucket.
