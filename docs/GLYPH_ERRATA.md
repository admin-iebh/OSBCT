### Why these look like one fault, not eighteen

- `è` U+00E8 — lowercase counterpart of the mapped È→ā
- `ó` U+00F3 — lowercase counterpart of the mapped Ó→ṇ
- `ê` U+00EA — lowercase counterpart of the mapped Ê→ī
- `¥` U+00A5 — uppercase counterpart of the mapped Ñ→ṁ
- `ÿ` U+00FF — same reading as þ; two code points for one letter
- `Ø` U+00D8 — third code point reading ā, with È and è
- `±` U+00B1 — fourth code point reading ā
- `õ` U+00F5 — same reading as the majority of ò
- `í` U+00ED — same reading as ê
- `ò` U+00F2 — lowercase counterpart of the mapped Ò→ñ — which is exactly the minority reading
